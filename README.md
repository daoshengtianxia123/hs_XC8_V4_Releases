# HS MCU Tools 安装包

这里公开发布 HS MCU Tools 的 VS Code 插件安装包。打开右侧 **Releases**，下载适合的 `.vsix` 文件，在 VS Code 中执行“扩展：从 VSIX 安装”。

## 安装包类型

- `xc8-win64`：Windows x64 常规版，包含编译工具链。
- `lite`：跨平台精简版；编译器需要按本机平台配置。
- `restricted-xc8-win64`：Windows x64 受限版，编译、下载及仿真操作不可执行。
- 文件名含 `ai-`：包含 AI 功能；不含 `ai-`：不打包 AI 功能。
- 文件名含 `3011a`：适用于旧版 HS16P3011 A（128 字节 RAM、5 级栈）；不含 `3011a` 的版本适用于 B（160 字节 RAM、8 级栈）。

## v0.2.106

修复 XC8 V1.45 在中文路径的多源码工程中无法打开合并文件引用源码的问题。已使用 HS16P3011 V2.00B 三源码工程完成编译，并生成 HEX。本次提供 A 版 3 个和 B 版 6 个安装包。
